# -TopCV-Web-Scrapper
Project sử dụng thư viện BeautifulSoup, và Requests trong môi trường jupyter notebook để lấy dữ liệu đăng tin tuyển dụng trong lĩnh vực Data Analyst trên TopCV.

Thành công scrapper trên cả 2 môi trường Jupyter notebook và VS Code.

Vấn đề hiện tại Status: 403, TopCV chặn ko cho scrapper trên môi trường github, nên ko thể tự động github actions cập nhật job được.
